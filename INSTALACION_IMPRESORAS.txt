REQUISITOS PREVIOS:
  - Node.js instalado (https://nodejs.org)
  - Impresoras Xprinter XP-80C encendidas y en la misma red

IPs DE LAS IMPRESORAS:
  - Cocina:  192.168.123.200
  - Caja:    192.168.123.100
  - Puerto:  9100 (estandar ESC/POS)


═══════════════════════════════════════════════════════════════
  INSTALACION AUTOMATICA (RECOMENDADO)
═══════════════════════════════════════════════════════════════

  1. Copiar la carpeta "pikta-print-server" a:
     C:\Users\USUARIO\pikta-print-server\

  2. Copiar el archivo "instalar-print-server.bat" al escritorio

  3. Hacer clic derecho en "instalar-print-server.bat"
     y seleccionar "Ejecutar como administrador"

  4. Esperar a que termine la instalacion

  5. LISTO. El servidor de impresion arrancara solo
     cada vez que la PC se encienda.


═══════════════════════════════════════════════════════════════
  INSTALACION MANUAL (SI LO ANTERIOR NO FUNCIONA)
═══════════════════════════════════════════════════════════════

  PASO 1: Instalar dependencias
  -----------------------------
  Abrir PowerShell y ejecutar:

    cd C:\Users\USUARIO\pikta-print-server
    npm install

  PASO 2: Iniciar el servidor
  -----------------------------
  Ejecutar:

    node server.js

  Deberias ver:

    PIK'TA Print Server v2.0
    Puerto: 3001
    Cocina:  192.168.123.200:9100
    Caja:    192.168.123.100:9100

  NO CERRAR ESTA TERMINAL.

  PASO 3: Configurar auto-start (opcional)
  -----------------------------------------
  Ejecutar en PowerShell:

    npm install -g pm2
    pm2 start server.js --name pikta-print
    pm2 save
    npm install -g pm2-windows-startup
    pm2-startup install


═══════════════════════════════════════════════════════════════
  CONFIGURACION EN RENDER
═══════════════════════════════════════════════════════════════

  Si el servidor de impresion esta en la misma PC que
  accede a Render, NO necesitas configurar nada en Render.

  El print server busca trabajos de impresion en Render
  automaticamente cada 5 segundos.

  Si quieres usar un servidor externo, agregar en Render
  > Environment:

    Key:   PRINT_SERVER_URL
    Value: http://IP_DEL_SERVIDOR:3001


═══════════════════════════════════════════════════════════════
  COMO FUNCIONA
═══════════════════════════════════════════════════════════════

  1. Cliente pide algo -> Mesero ingresa pedido en MESERO
  2. Admin cobra en POS
  3. Render guarda el pedido como "pendiente de impresion"
  4. El print server (en tu PC) busca trabajos cada 5 segundos
  5. Encuentra el trabajo -> lo envia a la impresora
  6. La impresora imprime el ticket automaticamente

  TODO OCURRE SIN NGROK NI URLs EXTERNAS.
  El print server se comunica directamente con Render.


═══════════════════════════════════════════════════════════════
  VERIFICAR QUE TODO FUNCIONA
═══════════════════════════════════════════════════════════════

  1. Abrir navegador e ir a: http://localhost:3001/health
  2. Deberia mostrar:

     {
       "status": "ok",
       "printers": {
         "cocina": { "status": "ok", "ip": "192.168.123.200" },
         "caja": { "status": "ok", "ip": "192.168.123.100" }

     - Verificar que este encendida
     - Verificar que este en la misma red
     - Hacer ping: ping 192.168.123.200


═══════════════════════════════════════════════════════════════
  SOLUCION DE PROBLEMAS
═══════════════════════════════════════════════════════════════

  PROBLEMA: No imprime
  SOLUCION:
  1. Verificar que las impresoras esten encendidas
  2. Verificar que el print server este corriendo
     Ejecutar: pm2 status
  3. Verificar conexion: http://localhost:3001/health
  4. Verificar que la PC pueda hacer ping a las impresoras

  PROBLEMA: El servidor no arranca solo al encender la PC
  SOLUCION:
  1. Ejecutar como administrador: instalar-print-server.bat
  2. O ejecutar manualmente: pm2-startup install

  PROBLEMA: Error "ECONNREFUSED"
  SOLUCION:
  1. Verificar que las IPs de las impresoras sean correctas
  2. Verificar que esten en la misma red
  3. Reiniciar la impresora

  PROBLEMA: Quiero cambiar las IPs de las impresoras
  SOLUCION:
  1. Editar C:\Users\USUARIO\pikta-print-server\printer.js
  2. Cambiar las lineas:
     const PRINTER_COCINA = '192.168.123.200';
     const PRINTER_CAJA = '192.168.123.100';
  3. Reiniciar: pm2 restart pikta-print
